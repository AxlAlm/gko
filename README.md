# gko

Humans are bad at multitasking and switching context is very draining. Instead of having managing multiple agents working on many different its better to make them work with you to do one things fasters.


## Reasons why you need this?


### example work flow that exists today

You start a chat your agent gets to work, then you wait for it to finish. While waiting to finish you maybe start a new chat to start some other work. Suddenly you have a few chats open and jumping between tabs and switching contexts. This way of working is not as efficient as one might think, its draining and its also not as fun.

### missing the flow

i miss the flow state you get into when coding.
